전체 생산 흐름

FAB → SEMI → Packaging → FIN

로트 투입

제품과 웨이퍼 수량을 선택해 새 FAB 로트를 시작합니다.

FAB 공정실적

DIFF부터 TEST까지 8개 공정을 기록하며 BOM 자재와 불량을 반영합니다.

SEMI 자동 입고

TEST Pass 시 로트가 Done이 되고 반제품과 AUTO_FAB 실적이 생성됩니다.

패키징

SEMI를 소비하고 PKG BOM 자재를 차감해 완제품을 생산합니다.

FIN 완제품

FIN 재고와 AUTO_PACK 제품실적이 생성되며 원본 로트까지 추적됩니다.

데이터는 언제 바뀌나요?

외부 연동 시 꼭 확인

이 MES의 기본 데이터셋은 소스코드에 고정된 픽스처(mes_core/dataset.json)입니다. 난수로 만들어내지 않으므로 코드를 고쳐도 값이 바뀌지 않습니다.

기동할 때만 초기화

컨테이너가 새로 뜰 때(재기동 · 재배포) 픽스처를 다시 적재합니다. 그 외에는 초기화되지 않습니다.

이력은 3개월 전부터

기동 시각 기준 90일 전부터 시작하도록 날짜만 통째로 밀어 넣습니다. 각 공정의 소요시간과 공정 간 간격은 그대로 보존됩니다.

운영 중 입력은 유지

API · MCP · 화면으로 만든 데이터는 앱이 떠 있는 동안 유지됩니다. 되돌리려면 리비전을 재기동하세요.

키는 삭제 방지

다른 로트 · BOM · 공정실적이 참조 중인 제품 · 설비는 삭제되지 않습니다(REST 409). 제품코드 · 설비ID 자체는 수정할 수 없습니다.

센서 데이터처럼 로트의 in_time · out_time 구간에 맞춰 저장하는 시스템이라면, 날짜가 매일 하루씩 밀리므로 구간 값을 캐시하지 말고 get_lot 등으로 그때그때 조회하세요. 날짜를 완전히 고정하려면 MES_HISTORY_START 환경변수를 지정하면 됩니다.
