How to use Mock MES

반도체 생산 흐름을 한 번에 데모하세요

하나의 SQLite 데이터베이스를 웹 콘솔, REST API, MCP 서버가 함께 사용합니다. 웹에서 사람이 입력한 결과와 에이전트가 처리한 결과가 같은 로트·재고·실적에 반영됩니다.

로트 투입 시작API 문서 열기MCP 문서 열기

전체 생산 흐름

FAB → SEMI → Packaging → FIN

로트 투입

제품과 웨이퍼 수량을 선택해 새 FAB 로트를 시작합니다.

FAB 공정실적

DIFF부터 TEST까지 8개 공정을 기록하며 BOM 자재와 불량을 반영합니다.

SEMI 자동 입고

TEST Pass 시 로트가 Done이 되고 반제품과 AUTO_FAB 실적이 생성됩니다.

패키징

SEMI를 소비하고 PKG BOM 자재를 차감해 완제품을 생산합니다.

FIN 완제품

FIN 재고와 AUTO_PACK 제품실적이 생성되며 원본 로트까지 추적됩니다.

웹 콘솔

HUMAN
