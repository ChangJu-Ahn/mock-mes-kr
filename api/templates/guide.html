사용법 & 공정 흐름 Guide

이게 뭔가요? What is this?

반도체 팹을 흉내 낸 목업 MES입니다. 하나의 SQLite DB를 세 가지 창구로 노출합니다: 사람용 웹 콘솔, 에이전트용 REST API, 에이전트용 MCP 서버. 콜드 스타트마다 데이터가 새로 시딩됩니다. 데모 전용이라 실제 보안은 없습니다.

전체 흐름 Overall flow

  1. 로트 투입 (Start lot) — 제품을 골라 웨이퍼 로트를 시작합니다. 첫 FAB 공정에서 Running.
  2. 공정실적 (Process result) ×8 — DIFF→PHOTO→ETCH→IMPL→CVD→CMP→METRO→TEST 순으로 이동. 각 이동은 BOM에 따라 자재를 차감하고, 불량(scrap)을 기록합니다.
  3. SEMI 자동 입고 — 마지막 FAB 공정(TEST) Pass 시 로트가 Done이 되고 반제품(SEMI)이 제품 인벤토리에 자동 입고 + 제품실적(AUTO_FAB) 생성.
  4. 패키징 (Packaging) — SEMI를 소비해 완제품(FIN)을 만듭니다. PKG 공정 BOM 자재도 차감, 제품실적(AUTO_PACK) 생성.
  5. 조회 — 재공(WIP), 제품/자재 인벤토리, 제품/공정 실적, 로트 이력을 언제든 조회.

Materials ──(BOM×wafers)──▶ Process results ──(TEST pass)──▶ SEMI ──(Packaging)──▶ FIN

에이전트 연결 Agent access

REST와 MCP는 헤더 X-API-Key: changjuahn가 필요합니다. 웹 콘솔과 /api/docs는 공개입니다.

REST (Product·Material·BOM):

curl -H "X-API-Key: changjuahn" https://<fqdn>/api/product-inventory
curl -X POST -H "X-API-Key: changjuahn" -H "Content-Type: application/json" \
     -d '{"product_code":"LX9","in_qty":50}' https://<fqdn>/api/packaging

MCP (Process·Lot), streamable HTTP at /mcp with the same header. Tools: start_lot, register_process_result, get_lot, list_lots, get_process_route, list_process_results, get_wip.

Full REST reference: /api/docs.
